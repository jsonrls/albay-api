# Albay places API

Static JSON for every tourist attraction, beach, resort, private resort, hotel, food spot, heritage site, nature area, fall, spring, trail, staycation, homestay, shop and venue in Albay, Philippines — sliced so a client only downloads what it needs.

There is no server here. Every file is served as-is from the CDN, so requests cost nothing and never rate-limit.

## Endpoints

| File | Contents |
| --- | --- |
| `index.json` | Manifest: totals, every category and LGU with its count and file path |
| `places.json` | The whole dataset in one file |
| `by-category/<slug>.json` | One category, e.g. `by-category/beaches.json` |
| `by-lgu/<slug>.json` | One municipality, e.g. `by-lgu/legazpi-city.json` |

Category slugs: `tourist-attractions`, `beaches`, `resorts`, `private-resorts`, `hotels`, `food`, `heritage`, `nature-sanctuaries`, `falls-and-springs`, `hiking-and-camping`, `adventure-activities`, `staycations`, `homestays-and-farmstays`, `shopping-and-souvenirs`, `events-and-venues`.

## Record shape

```jsonc
{
  "id": "71e75a654bd0773a",        // Google place CID
  "googleFeatureId": "11yqsd",
  "slug": "view-point-221",
  "name": "View point 221",
  "categories": ["tourist-attractions"],
  "categoryLabels": ["Tourist Attractions"],
  "primaryType": "Tourist attraction",  // Google's own label
  "locality": "Oas, Albay",
  "lgus": ["Oas"],                       // all 21 Albay LGUs
  "address": "8HHM+JX, Oas, Albay",
  "plusCode": "8HHM+JX",
  "coordinates": { "lat": 13.3291118, "lng": 123.5849516 },
  "rating": 5,
  "reviewsCount": 1,
  "priceHint": "₱2,412",
  "hours": "Open · Closes 9 PM",
  "amenities": ["Pool", "Free parking"],
  "phone": null,
  "website": null,
  "googleMapsUrl": "https://www.google.com/maps/place/..."
}
```

Empty fields are omitted rather than sent as `null`.

## Known gaps

- `phone` and `website` are rarely populated: Google's search result cards do not carry them, and most single-result place pages do not render them either.
- `address` is often a plus code or a barangay fragment; `locality`, `plusCode` and `coordinates` are the reliable location fields.
- Coverage is a work in progress while the scrape runs. `index.json` → `total` is the live count.

## Source and refresh

Generated by `scripts/build-albay-api.mjs` in the `bicol-travel-directory` app, which publishes `data/albay/albay-places.json` (a Playwright pass over Google Maps search results for each of Albay's 21 LGUs) into this tree. Re-run `npm run publish:api` there, then commit and push.

The rows are scraped Google Maps content, whose licensing does not permit republishing them as your own database. Treat this endpoint as internal staging and seed data, and build anything public-facing on sources you can cite — the DOT accreditation lists published by the Provincial Tourism, Culture and Arts Office of Albay, and LGU tourism offices.
